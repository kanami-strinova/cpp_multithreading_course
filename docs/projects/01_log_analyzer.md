# 📊 项目一：并发日志分析器

## 项目目标

创建一个高性能的日志分析工具，能够：
- 多线程并发读取大型日志文件
- 实时统计错误、警告、信息等
- 生成分析报告

## 功能需求

### 核心功能
1. **多线程文件读取**
   - 将大文件分块
   - 每个线程处理一块

2. **实时统计**
   - 统计各类型日志数量
   - 计算错误率、警告率

3. **性能监控**
   - 显示处理进度
   - 计算吞吐量

### 输出示例
```
=== 日志分析报告 ===
总行数: 1,000,000
错误数: 5,234 (0.52%)
警告数: 12,345 (1.23%)
信息数: 982,421 (98.25%)

处理时间: 2.5 秒
吞吐量: 400 MB/s
```

## 技术要点

```cpp
// 1. 文件分块
size_t chunk_size = file_size / num_threads;
std::vector<std::thread> workers;

// 2. 线程安全统计

// 3. 线程池
ThreadPool pool(std::thread::hardware_concurrency());
```
