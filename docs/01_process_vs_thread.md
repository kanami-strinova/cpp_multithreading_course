# 📚 第一章：进程与线程

## 1.1 基本概念

### 什么是进程？

**进程（Process）** 是操作系统分配的独立运行单元。

```
┌─────────────────────────────────┐
│           进程 A                 │
│  ┌─────────────────────────────┐│
│  │ 代码段  │ 数据段 │ 堆栈 │ PCB ││
│  └─────────────────────────────┘│
└─────────────────────────────────┘
```

### 什么是线程？

**线程（Thread）** 是进程内的执行单元，共享进程资源。

```
┌─────────────────────────────────┐
│           进程 A                 │
│  ┌─────────────────────────────┐│
│  │   共享资源：代码/数据/堆    ││
│  ├─────────────────────────────┤│
│  │ 线程1: Stack1 │ 线程2: Stack2││
│  ├─────────────────────────────┤│
│  │      线程3: Stack3          ││
│  └─────────────────────────────┘│
└─────────────────────────────────┘
```

## 1.2 关键区别

| 特性 | 进程 | 线程 |
|------|------|------|
| 创建开销 | 大 | 小 |
| 通信方式 | IPC（管道、消息队列等） | 共享内存 |
| 资源占用 | 独立地址空间 | 共享地址空间 |
| 隔离性 | 强 | 弱 |
| 并发性 | 可实现 | 天然支持 |

## 1.3 C++ 中的线程

```cpp
#include <thread>
#include <iostream>

// 线程函数
void hello() {
    std::cout << "Hello from thread!\n";
}

int main() {
    // 创建线程
    std::thread t(hello);
    
    // 主线程继续执行
    std::cout << "Hello from main!\n";
    
    // 等待线程结束
    t.join();
    
    return 0;
}
```

## 1.4 为什么使用线程？

### 优势

1. **资源利用率**: I/O 等待时可执行其他任务
2. **响应性**: UI 线程不被阻塞
3. **并行性**: 多核利用
4. **简单通信**: 共享内存直接交互

### 挑战

1. **数据竞争**: 多个线程访问共享数据
2. **死锁**: 线程互相等待对方释放锁
3. **调试困难**: 执行顺序不确定
4. **资源消耗**: 线程创建有开销
