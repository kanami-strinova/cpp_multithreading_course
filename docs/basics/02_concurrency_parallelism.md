# 并发与并行

## 基本概念

### 并发（Concurrency）
多个任务在重叠的时间段内执行

```
时间 →
线程1: |████  ░░░░  |████|
线程2: |░░░░  |████  |░░░░|
```

### 并行（Parallelism）
多个任务真正同时执行（需要多核）

```
时间 →
CPU1: |████████|
CPU2: |████████|
```

## C++ 中的实现

### 并发
```cpp
// 单核也能实现并发
std::thread t([]{ ... });
```

### 并行
```cpp
// 需要多核
std::vector<std::thread> threads;
for (int i = 0; i < cores; ++i) {
    threads.emplace_back(task, i);
}
```

## 何时使用

| 场景 | 推荐方案 |
|------|----------|
| I/O 密集 | 并发（单核足够） |
| CPU 密集 | 并行（需要多核） |
| 混合任务 | 两者结合 |
